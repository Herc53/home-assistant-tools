# Home Assistant Tools

A collection of scripts, blueprints and other tools for extending a [Home Assistant](https://www.home-assistant.io/) setup.

## Purpose

This repository gathers reusable pieces that make home automation easier to build and maintain, such as:

- **Blueprints**: reusable automation and script templates that can be imported into Home Assistant.
- **Scripts**: helper scripts for automating tasks around a Home Assistant instance.
- **Other tools**: configuration snippets, utilities and anything else useful for extending a smart home.

## Usage

Browse the repository and pick what you need. Each tool should come with its own short description or usage notes.
